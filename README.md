# تقييم ومتابعة مرافق مباني الإسكان الطلابي

نظام رقابي ومتابعة ميدانية وتوأم معماري لمرافق 34 مبنى سكني جامعي.

---

## الميزات الأساسية

1. **بوابة دخول مشفرة ومحمية**:
   - الدخول مقفل افتراضياً ويتطلب كلمة مرور المشرف العام أو كود الدخول الخاص برائد المبنى.
   - لا توجد أي كلمات مرور مخزنة في الكود المصدري.

2. **سجل مستقل لـ 34 رائد مبنى**:
   - كود دخول فريد ومستقل لكل مبنى سكني.
   - إمكانية تقمص المشرف لدور أي رائد مبنى لإدخال أو مراجعة البيانات.

3. **لوحة تحكم الصلاحيات والميزات**:
   - إمكانية تفعيل أو تعطيل الميزات (المجسم ثلاثي الأبعاد، استمارة الفحص، رفع الصور، التقارير الرسمية، العرض العام).

4. **مصفوفة المرافق الثابتة**:
   - جناح 1 و 2: 3 مراحيض، 3 مراوش، 3 مغاسل، 1 سخان، 1 شفاط، 1 تصريف.
   - جناح 3 و 4: مرحاضين، مروشين، مغسلتين، سخانين، 1 شفاط، 1 تصريف.

5. **سجل العمليات والرقابة**:
   - تسجيل زمني لجميع عمليات الفحص والتعديلات وتوثيقات المشرف ورواد المباني.

---

## التشغيل المحلي

```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. إعداد المتغيرات البيئية (نسخ القالب)
cp .env.example .env.local
# ثم قم بتعبئة مفاتيح مشروع Firebase الخاص بك في ملف .env.local

# 3. تشغيل خادم التطوير المحلي
npm run dev
```
